# Gemini MCP-сервер — инструкция по запуску

Этот сервер даёт Claude инструмент «сгенерировать картинку», который
внутри себя обращается к Gemini API с вашим ключом. Ключ хранится
только на вашем хостинге, Claude его никогда не видит.

## Шаг 1. Получить бесплатный ключ Gemini

1. Зайдите на https://aistudio.google.com/apikey
2. Нажмите «Create API key».
3. Скопируйте ключ (выглядит как `AIzaSy...`).

## Шаг 2. Выложить код в GitHub

1. Создайте новый репозиторий на GitHub (можно приватный),
   например `gemini-mcp-server`.
2. Загрузите туда файлы `index.js`, `package.json` и этот `README.md`
   (три файла из этой папки).

## Шаг 3. Развернуть на bothost.ru

Точно так же, как вы разворачивали Telegram-бота:

1. В панели bothost.ru создайте новый проект → «Деплой из GitHub» →
   выберите репозиторий `gemini-mcp-server`.
2. В настройках проекта откройте раздел «Переменные окружения» и
   добавьте:
   - `GEMINI_API_KEY` = ваш ключ из шага 1
3. Убедитесь, что тип проекта — «Web» / «HTTP-сервис» (не «бот»),
   чтобы bothost выдал публичный HTTPS-домен (что-то вроде
   `gemini-mcp-xxxx.bothost.ru`).
4. Запустите деплой.
5. В логах должна появиться строка
   `Gemini MCP-сервер запущен на порту ...` — значит, всё работает.

## Шаг 4. Проверить вручную (необязательно)

Откройте в браузере `https://ваш-домен.bothost.ru/` — должна
показаться строка «Gemini MCP-сервер работает. MCP-эндпоинт: /mcp».

## Шаг 5. Подключить в Claude

1. В Claude откройте «Connectors» → «Add».
2. В качестве адреса сервера укажите:
   `https://ваш-домен.bothost.ru/mcp`
   (обязательно с `/mcp` на конце — это путь, который слушает сервер).
3. Тип авторизации — «No auth» / без авторизации (сервер сам защищён
   тем, что о его адресе никто, кроме вас, не знает; при желании
   позже можно добавить проверку секретного заголовка).
4. Сохраните — коннектор должен подключиться без ошибок про
   «invalid MCP server», потому что это уже настоящий MCP-сервер, а
   не страница сайта.

## Если что-то не работает

- Ошибка про модель Gemini (`model not found`) — зайдите на
  https://ai.google.dev/gemini-api/docs/image-generation и проверьте
  актуальное имя модели, затем добавьте переменную окружения
  `GEMINI_IMAGE_MODEL` с правильным значением в bothost.ru.
- Пришлите скриншот ошибки — разберём вместе.
